# Agent control plane

Which skills, agents and hooks each of my projects gets, for Claude Code and Codex.
Managed with [acp](https://github.com/thieung/acp).

```bash
acp                 # fleet status
acp add ~/code/app  # add a repo and sync it
acp web             # local UI
```

See `AGENTS.md` for the layout and the rules agents follow here.
