One control plane. Every repo and worktree in step.Một control plane. Đồng bộ mọi repo và worktree.

acp manages the skills, agents and hooks that Claude Code and Codex get in each project, at the AgentKit version you pinned. It links your own skills, reaches into every git worktree, and hands a broken install to a coding agent that tries to repair it.

acp quản lý skills, agents và hooks mà Claude Code và Codex nhận được ở mỗi project, theo đúng phiên bản AgentKit bạn đã ghim. Nó link các skill của riêng bạn, phủ tới từng git worktree, và giao bản cài bị hỏng cho một coding agent để thử sửa.

uv tool install git+ssh://git@github.com/thieung/acp.git

Get startedBắt đầu

1

Install acp and akCài acp và ak

ak installs AgentKit into a repo. acp decides what each repo should have and keeps every repo and worktree that way.

ak cài AgentKit vào một repo. acp quyết định mỗi repo cần có gì và giữ mọi repo, mọi worktree đúng như thế.

You need Python 3.10 or newer, uv, and an SSH key that GitHub accepts for thieung/acp. ssh -T git@github.com should greet you by name.

Bạn cần Python 3.10 trở lên, uv, và một SSH key được GitHub chấp nhận cho thieung/acp. Lệnh ssh -T git@github.com phải chào đúng tên bạn.

uv tool install git+ssh://git@github.com/thieung/acp.git
acp setup

You should seeKết quả mong đợi

ak       3.0.0-beta.36  (/Users/you/.local/bin/ak)
login    signed in (api_key)
doctor   healthy

If ak is missing, let acp run AgentKit's official installer, then sign in. Without --apply, acp setup install-ak only shows what it would run.

Nếu chưa có ak, để acp chạy installer chính thức của AgentKit rồi đăng nhập. Không có --apply thì acp setup install-ak chỉ hiện những gì nó sẽ chạy.

acp setup install-ak --apply
ak onboard

Update acp later with uv tool upgrade acp. pipx works too: pipx install git+ssh://git@github.com/thieung/acp.git.

Cập nhật acp sau này bằng uv tool upgrade acp. Dùng pipx cũng được: pipx install git+ssh://git@github.com/thieung/acp.git.

2

Create a control planeTạo control plane

A small folder of JSON files that says what every project should have. Put it in git so the decisions travel with you.

Một thư mục nhỏ gồm các file JSON, ghi rõ mỗi project cần có gì. Hãy để nó trong git để các quyết định đi theo bạn sang máy khác.

acp init ~/agent-control-plane

You should seeKết quả mong đợi

created control plane /Users/you/agent-control-plane
default root recorded in /Users/you/.config/acp/config.json
next: `acp setup` to check ak, then `acp add <repo>` for each project, then `acp web`

The recorded default lets every later command run from any folder. To keep the plane in git, run git init inside it and commit; machine paths and backups are already in its .gitignore. What each file holds is under Files.

Nhờ mặc định đã ghi, mọi lệnh sau đó chạy được từ bất kỳ thư mục nào. Muốn đưa control plane vào git, chạy git init bên trong rồi commit; đường dẫn máy và bản sao lưu đã nằm sẵn trong .gitignore. Mỗi file chứa gì có ở mục File.

3

Add a projectThêm một project

Point acp at the main checkout of a repo. It writes the manifest, records where the repo lives on this machine, and syncs it.

Chỉ cho acp thư mục checkout chính của một repo. Nó ghi manifest, lưu vị trí repo trên máy này và sync repo đó.

Replace ~/code/my-app with your own repo. Look first, then add:

Thay ~/code/my-app bằng repo của bạn. Xem trước, rồi mới thêm:

acp add ~/code/my-app --dry-run
acp add ~/code/my-app

You should see, after AgentKit's own install outputKết quả mong đợi, sau phần output cài đặt của AgentKit

added my-app -> /Users/you/code/my-app  (edit projects/my-app.json for personal skills)
my-app  /Users/you/code/my-app  in sync

A new project gets AgentKit's engineer kit on the beta channel, for Claude Code and Codex. Pass --no-agentkit for personal skills only, or choose with --kit, --channel and --targets. The manifest it writes:

Project mới nhận kit engineer của AgentKit ở kênh beta, cho Claude Code và Codex. Dùng --no-agentkit nếu chỉ cần skill cá nhân, hoặc tự chọn bằng --kit, --channel, --targets. Manifest nó ghi ra:

{
  "id": "my-app",
  "agentkit": { "kit": "engineer", "channel": "beta", "targets": ["claude-code", "codex"], "skills": "all" },
  "skills": []
}
4

Check and sync itKiểm tra và sync

Run acp on its own to see every project. A check mark means the repo matches its manifest.

Gõ acp không kèm gì để xem mọi project. Dấu tích nghĩa là repo khớp với manifest của nó.

acp

You should seeKết quả mong đợi

PROJECT  AGENTKIT                              PERSONAL  WORKTREES
my-app   cc 3.0.0-beta.36 codex 3.0.0-beta.36  0/0       -          ✓
pinned: beta/engineer 3.0.0-beta.36

When a project drifts, because you edited its manifest or AgentKit moved, sync it from inside the repo. The dry run lists each change first.

Khi một project bị lệch, do bạn sửa manifest hoặc AgentKit có bản mới, hãy sync nó từ trong repo. Bản dry run liệt kê từng thay đổi trước.

cd ~/code/my-app
acp sync --dry-run
acp sync

You should seeKết quả mong đợi

my-app  /Users/you/code/my-app  in sync

A sync installs or refreshes AgentKit at the pinned version, links your personal skills, and links every worktree to the main checkout's agent files. If it fails, see When a sync fails.

Một lần sync cài hoặc làm mới AgentKit theo bản đã ghim, link skill cá nhân, và link mọi worktree tới file agent của checkout chính. Nếu lỗi, xem Khi sync lỗi.

5

See it in the web UIXem trên web UI

The same projects in a browser, on your machine only. Each button runs one allowed acp command and shows the exact command it ran.

Cùng các project đó trong trình duyệt, chỉ chạy trên máy bạn. Mỗi nút chạy đúng một lệnh acp được cho phép và hiện chính xác lệnh đã chạy.

acp web

You should see, and your browser opens itKết quả mong đợi, trình duyệt tự mở địa chỉ này

acp web: http://127.0.0.1:8780/#token=…
  • Click a project's status to see what is wrong and the dry run of what a sync would change.
  • "Sync" applies that plan. "Sync, thay bản cũ" also replaces old copied folders in worktrees with links, after backing them up; see Worktrees with old copies.
  • The skills drawer previews every change before Apply is enabled.
  • The web UI itself is in Vietnamese for now.
  • Bấm vào tình trạng của project để xem đang bị gì và bản dry run của những gì sync sẽ đổi.
  • "Sync" áp dụng kế hoạch đó. "Sync, thay bản cũ" còn thay các thư mục copy cũ trong worktree bằng link, sau khi đã sao lưu; xem Worktree có bản copy cũ.
  • Drawer skills xem trước mọi thay đổi rồi mới bật nút Áp dụng.

Going furtherDùng nhiều hơn

Change a project's skillsĐổi skill của một project

Rather than editing JSON by hand, ask acp. It prints the manifest diff and what the sync would do, and changes nothing until you add --apply.

Thay vì sửa JSON bằng tay, hãy để acp làm. Nó in diff của manifest và những gì sync sẽ làm, và không đổi gì cho đến khi bạn thêm --apply.

acp skills list my-app
acp skills set my-app --add release-notes --remove ak-shopify
acp skills set my-app --add release-notes --remove ak-shopify --apply

Personal skills live in the control plane's skills/ folder, one folder per skill. acp kit add my-app gives AgentKit to a project that was added without it.

Skill cá nhân nằm trong thư mục skills/ của control plane, mỗi skill một thư mục. acp kit add my-app thêm AgentKit cho project lúc thêm vào chưa có.

Many projects and worktreesNhiều project và worktree

Once several repos are in, work on all of them at once. Check the plan before a sync that touches everything.

Khi đã có nhiều repo, bạn có thể xử lý tất cả cùng lúc. Hãy xem kế hoạch trước khi chạy một lần sync chạm tới mọi thứ.

acp sync --all --dry-run

Then run acp sync --all. In CI, acp doctor exits with 1 when any project drifted.

Sau đó chạy acp sync --all. Trong CI, acp doctor trả mã 1 khi có project bị lệch.

New worktreesWorktree mới

Worktrees appear all the time. Install the session hook once, and Claude Code and Codex link each new worktree when a session starts in it.

Worktree mới sinh ra liên tục. Cài session hook một lần, Claude Code và Codex sẽ tự link worktree mới khi một phiên bắt đầu trong đó.

acp hooks install --dry-run
acp hooks install

Worktrees with old copiesWorktree có bản copy cũ

A worktree created before acp may hold a real .claude folder copied from main, which hides newer skills. A sync leaves it alone and reports it. --adopt moves each such folder into runtime/backups and puts a link in its place.

Worktree tạo trước khi có acp có thể chứa thư mục .claude thật được copy từ main, che mất các skill mới hơn. Sync thường để nguyên và báo lại. --adopt chuyển từng thư mục đó vào runtime/backups rồi đặt link vào chỗ cũ.

acp sync my-app --adopt --dry-run
acp sync my-app --adopt

A new AgentKit releaseBản AgentKit mới

acp upgrade updates ak, pins the channel's latest kit in the lock file and syncs every project. acp upgrade --dry-run shows the versions first.

acp upgrade cập nhật ak, ghim kit mới nhất của kênh vào file lock và sync mọi project. acp upgrade --dry-run cho xem phiên bản trước.

Connect an agentKết nối agent

Ask your agent "which projects need a sync?" and it answers from acp_status. Ask it to add a skill and it shows you the manifest diff first, then applies it when you agree.

Hỏi agent "project nào cần sync?" và nó trả lời từ acp_status. Nhờ nó thêm một skill thì nó cho bạn xem diff của manifest trước, rồi mới áp dụng khi bạn đồng ý.

Connect once per machine. --scope user makes acp available in every Claude Code project.

Mỗi máy chỉ cần kết nối một lần. --scope user giúp acp có mặt trong mọi project của Claude Code.

claude mcp add --scope user acp -- acp mcp
codex mcp add acp -- acp mcp

To confirmĐể kiểm tra

Run claude mcp list or codex mcp list. acp should be listed; Claude Code also shows it as connected.

Chạy claude mcp list hoặc codex mcp list. acp phải có trong danh sách; Claude Code còn hiện nó là đã kết nối.

The server works on the control plane acp init recorded. To point it elsewhere, pass ACP_ROOT: -e ACP_ROOT=/path for Claude Code, --env ACP_ROOT=/path for Codex. Any other MCP client can launch acp mcp over stdio.

Server làm việc trên control plane mà acp init đã ghi. Muốn trỏ chỗ khác, truyền ACP_ROOT: -e ACP_ROOT=/path với Claude Code, --env ACP_ROOT=/path với Codex. Client MCP khác cũng chạy được acp mcp qua stdio.

Tools that only read run straight away. Tools that change things return a preview unless the agent passes apply: true, and your client still asks you before calls it is not allowed to make on its own. The full list is under MCP tools.

Tool chỉ đọc chạy ngay. Tool có thay đổi trả về bản xem trước trừ khi agent truyền apply: true, và client vẫn hỏi bạn trước những lần gọi nó không được tự làm. Danh sách đầy đủ ở mục Tool MCP.

A sync started over MCP never opens a separate repair agent. If it fails, the agent you are talking to sees the error and fixes it with you.

Sync gọi qua MCP không bao giờ mở thêm agent sửa lỗi. Nếu lỗi, chính agent đang nói chuyện với bạn thấy lỗi và cùng bạn sửa.

When a sync failsKhi sync lỗi

From the terminal or the web UI, a failed install is handed to Claude Code or Codex inside fixed limits. acp then checks the result itself.

Từ terminal hay web UI, một lần cài lỗi được giao cho Claude Code hoặc Codex trong các giới hạn cố định. Sau đó acp tự kiểm tra kết quả.

Example: you hand-edited .claude/settings.json in my-app, left it invalid, and acp sync my-app fails.

Ví dụ: bạn sửa tay .claude/settings.json trong my-app, để nó sai cú pháp, và acp sync my-app lỗi.

  1. Back upmy-app's agent folders and its entries in the manifest, paths and lock are copied to runtime/fix-backups.
  2. Sao lưuThư mục agent của my-app cùng các mục của nó trong manifest, đường dẫn và lock được chép vào runtime/fix-backups.
  3. RepairThe agent reads the error, with secrets removed, repairs the JSON, and writes down the cause.
  4. SửaAgent đọc lỗi (đã lược bỏ secret), sửa file JSON và ghi lại nguyên nhân.
  5. Checkacp checks the limits below, runs the sync again and checks the project's status.
  6. Kiểm traacp soát các giới hạn bên dưới, chạy lại sync và kiểm tra tình trạng project.
FixedĐã sửa

The re-run passed. acp prints fix <op>: fixed with the cause, and acp fix show lists every file the agent changed.

Lần chạy lại đã qua. acp in fix <op>: fixed kèm nguyên nhân, và acp fix show liệt kê mọi file agent đã đổi.

Gave upDừng lại

Still failing after three attempts, or the cause is in the control plane or in ak, or it needs your decision. acp stops and writes plans/reports/acp-fix-<op>-my-app.md: the cause, where it is, and what it needs from you.

Vẫn lỗi sau ba lần thử, hoặc nguyên nhân nằm ở control plane hay ở ak, hoặc cần bạn quyết định. acp dừng và viết plans/reports/acp-fix-<op>-my-app.md: nguyên nhân, nằm ở đâu và cần gì từ bạn.

StoppedBị chặn

The agent changed something outside its limits. acp stops at once, puts the manifest back, and leaves the folders for you to restore with acp fix rollback.

Agent đã đổi thứ nằm ngoài giới hạn. acp dừng ngay, trả manifest về như cũ, và để bạn khôi phục các thư mục bằng acp fix rollback.

The agent may changeAgent được phép đổi

  • The project's .claude, .agents, .codex and .agentkit folders
  • That project's manifest, path and lock entries
  • Các thư mục .claude, .agents, .codex, .agentkit của project
  • Manifest, đường dẫn và mục lock của project đó

The agent neverAgent không bao giờ

  • Removes a skill or a target
  • Switches kit or channel
  • Edits the control plane's skills/, hooks/ or scripts/
  • Touches other files in your repo
  • Gỡ một skill hay một target
  • Đổi kit hoặc kênh
  • Sửa skills/, hooks/, scripts/ của control plane
  • Đụng tới file khác trong repo của bạn

Look back and undoXem lại và hoàn tác

Every repair keeps its backup, its diff and the agent's transcript. Take the session id from acp fix list:

Mỗi lần sửa đều giữ bản sao lưu, diff và transcript của agent. Lấy mã phiên từ acp fix list:

acp fix list
acp fix show <op> --transcript
acp fix rollback <op>          # shows what it would restore
acp fix rollback <op> --yes

Choose the agentChọn agent

acp fix config --target codex --runner direct picks the agent. direct runs it on your Claude or Codex subscription; ak-run uses ak run with an API key. Skip repairs for one run with --no-fix, or turn them off with acp fix config --auto off.

acp fix config --target codex --runner direct chọn agent. direct chạy bằng subscription Claude hoặc Codex của bạn; ak-run dùng ak run với API key. Bỏ qua tự sửa cho một lần chạy bằng --no-fix, hoặc tắt hẳn bằng acp fix config --auto off.
